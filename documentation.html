Gaa Saka Poultry Farm Management System

A comprehensive, modern, and robust software solution designed to digitize and automate the day-to-day operations of modern poultry farms.

1 Introduction

The Gaa Saka Poultry Farm Management System (PFMS) is engineered to solve the complex operational challenges faced by poultry farm managers. It unifies flock tracking, financial accounting, hardware security monitoring, and staff management into a single, cohesive interface.

Built with an emphasis on premium UI/UX and high performance, the platform ensures that critical metrics are always available at a glance, allowing farm owners to make data-driven decisions rapidly.

2 System Architecture

Technology Stack

Frontend

  • Next.js 16 (React Framework)
  • TailwindCSS (Styling & Design System)
  • Recharts (Data Visualization)
  • Lucide React (Iconography)

Backend & Database

  • Next.js App Router (API Routes)
  • Drizzle ORM (Database Query Builder)
  • SQLite (Lightweight relational database)
  • JOSE (JWT Authentication)

The application strictly follows a modular architecture separating data fetching logic from client-side state management. It leverages Next.js Server Components where applicable, passing serialized state down to highly interactive Client Components.

3 Dashboard & Analytics

The central dashboard acts as the nerve center of the farm. It aggregates data from all modules to provide real-time KPIs.

  • Egg Production Volume Chart: A comparative Bar Chart that tracks the daily collection of Good Eggs against Cracked/Spoilt Eggs. Mortality data has been intentionally decoupled from this chart to ensure strict focus on yield efficiency.
  • Sales & Revenue Trend: A Line Chart illustrating the monetary influx over selected time filters (Weekly, Monthly, Yearly).
  • Dynamic KPIs: Calculates Net Growth Percentages, Feed Conversion Ratios, and Break-Even Analysis based on incurred expenses versus projected flock value.
  • Alerts Queue: Flags critical system warnings such as low feed thresholds or offline CCTV arrays.

4 Egg Tracking

Inventory Mathematics Rule

The system enforces a strict conversion rule where 1 Crate = 30 Pieces. All logging modules dynamically convert pieces to crates to maintain standardized inventory units.

Egg logging categorizes output into three precise metrics:

  • Good Eggs: Saleable inventory.
  • Broken Eggs: Eggs damaged during collection or transport.
  • Spoilt Eggs: Unusable yield discarded due to biological defects.

5 Finance & Invoicing

The financial suite handles both the macro and micro economics of the farm.

Paid Invoices

Formerly categorized as "Active", these represent successfully closed transactions where capital has hit the farm accounts.

Unpaid Invoices

Outstanding accounts receivables. These are distinctly separated in the UI to allow managers to chase pending payments efficiently.

6 CCTV & Security

Physical farm security is integrated directly into the digital dashboard. The CCTV module allows for:

  • Live Status Monitoring: Visual indicators of camera uptime, jitter, and offline alerts.
  • Hardware Pairing: A built-in "Connect Camera" function that renders an NVR-SYNC-AWAIT QR Code. Staff can scan this code using a companion app or manually enter the Camera ID to provision new hardware to the surveillance array.
  • Technician Dispatch: Immediate logging of hardware faults assigned to maintenance teams.

7 AI Smart Logger

A flagship feature designed to eliminate manual data entry friction. The AI Smart Logger accepts conversational English and translates it directly into database transactions.

// Example User Input:

"Log that Abdulrahman Monsur collected 3 crates on Sunday. We bought 2k fuel and 3,500 vaccine today."


// AI Parses to JSON API payload mapping to:

1. Eggs Table -> +90 Pieces (Good)

2. Expense Table -> ₦2,000 (Fuel), ₦3,500 (Medical)

3. Staff Table -> Task associated with Abdulrahman

This is powered by Google's Gemini LLM utilizing strict JSON Schema validation.
