Installer Wizard Scope

What the /setup Installation Wizard Does

When you deploy or self-host PFMS, navigating to /setup opens the 5-step Installation & Deployment Wizard. It automatically runs a real-time connection ping guard on your database, seeds master Super Admin credentials, configures Paystack & Stripe merchant keys, sets transactional email APIs, and initializes default subscription pricing tiers.

Wizard Step 1 of 5

Database Engine Selection & Real-Time Connection Guard

Select your database engine and test live connectivity.

1
Select Database Engine Driver Choose between ⚡ Supabase Cloud PostgreSQL (recommended for multi-tenant Row-Level Security), 🐘 Standard PostgreSQL (AWS RDS / Neon), or 🐬 MySQL / MariaDB.
2
Verify Real-Time Connection Status Banner The system automatically pings your database endpoint. Verify that the banner displays Database connection verified 100%! Connection is live. before clicking Continue to Step 2.

Wizard Step 2 of 5

Master Super Admin Account Credentials & Platform Identity

1
Set Master Super Admin Email & Password Type your master platform owner email (e.g. owner@poultry.com or mansur@ankabit.com) and set a secure password.
2
Customize Application Name & Currency Symbol Type your platform brand title (Default: PFMS) and select your currency symbol (₦ NGN, $ USD, € EUR, £ GBP, KSh KES, GH₵ GHS).
Wizard Step 3 of 5

Payment Gateways Integration (Paystack & Stripe API Keys)

1
Configure Paystack Keys (African / NGN Checkouts) Enter paystackPublicKey (pk_test/pk_live...) and paystackSecretKey (sk_test/sk_live...).
2
Configure Stripe Keys (Global / USD Card Payments) Enter stripePublicKey (pk_test/pk_live...) and stripeSecretKey (sk_test/sk_live...).

Wizard Step 4 of 5

Transactional Email Gateway & Plan Pricing Defaults

1
Set Resend API Key & System Sender Email Enter your Resend API Key (re_...) and System Sender Email (e.g. support@pfms-poultry.com).
2
Configure Default SaaS Pricing Tiers Set default monthly & annual pricing for Commercial Pro Tier (₦15,000/mo) and Enterprise Plus Tier (₦45,000/mo).

Complete Installation & Save Platform Configuration

1
Click '⚡ Complete Installation & Save Config' Review your master summary card and click the green button marked ⚡ Complete Installation & Save Config.
2
Launch Super Admin Dashboard Click Open Super Admin Dashboard (`/dashboard/admin`) or Log In to Platform (`/login`).
