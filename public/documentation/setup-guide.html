Installation, Database Drivers & System Setup Guide

Step-by-step master technical guide for buyers and system administrators to deploy the Poultry Farm Management System (PFMS), configure database drivers (Supabase, Standard PostgreSQL, MySQL), set environment variables, and run the setup wizard.

1. Prerequisites & Environment Variable Reference

Before deploying the application, ensure Node.js 18+ or 20+ is installed. Create a `.env.local` file in your root project directory using the schema below: 

# Core Next.js Configuration
NODE_ENV=production
NEXT_PUBLIC_APP_URL=http://localhost:3000

# Database Connection (Supported Drivers: Supabase, Postgres, MySQL)
DATABASE_TYPE=supabase # Options: supabase | postgresql | mysql
DATABASE_URL=postgresql://postgres:yourpassword@db.yourhost.supabase.co:5432/postgres

# Supabase Credentials (Required for Managed Supabase Storage & Realtime)
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
SUPABASE_SERVICE_ROLE_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...

# Payment Gateways (Optional for Online Merchant Invoicing)
PAYSTACK_SECRET_KEY=sk_live_...
NEXT_PUBLIC_PAYSTACK_PUBLIC_KEY=pk_live_...
STRIPE_SECRET_KEY=sk_live_...
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=pk_live_...

2. Multi-Database Engine Driver Selection

PFMS features an engine-agnostic database abstraction layer supporting 3 major relational database drivers:

Driver 01 (Recommended)

Supabase PostgreSQL

Fully managed cloud PostgreSQL database with built-in row-level security (RLS), instant REST API generators, and automatic database backups.

Driver 02

Standard PostgreSQL

Self-hosted PostgreSQL 14/15/16 instances (AWS RDS, DigitalOcean Managed Database, or local Docker containers).

Driver 03

MySQL / MariaDB

MySQL 8.0+ or MariaDB 10.6+ instances commonly hosted on standard cPanel or Linux VPS servers.

3. Step-by-Step Setup Wizard Instructions

Step 1: Access `/setup`

Open your browser and navigate to `http://localhost:3000/setup`. If the database is not yet initialized, the app automatically redirects administrators to the setup wizard.

Step 2: Choose Database Engine Driver

Click on your preferred database driver card. Input your database host, port (default 5432 for Postgres, 3306 for MySQL), database name, username, and password.

Step 3: Automated Connection Guard Ping Test

The setup wizard executes an automated real-time ping test against the database server. If the connection fails (e.g. invalid password or host unreachable), the wizard displays exact error diagnostics and disables the 'Next' button until resolved.

Step 4: Initialize Farm Profile & Superadmin User

Input your main farm business name (e.g., "Grand Valley Poultry Farm"), initial housing pens, and create the root Superadmin credentials (`owner@poultry.com`). Click 'Complete Setup' to seed database tables and open the dashboard.
