Setup & Deployment Guide

Installation, Multi-Database Engine Drivers & Environment Setup

Prerequisites & Environment Variables

Before deploying the application, create a `.env.local` file in your root project directory using the schema below: 

# Core Next.js Configuration
NODE_ENV=production
NEXT_PUBLIC_APP_URL=http://localhost:3000

# Database Connection (Supported Drivers: Supabase, Postgres, MySQL)
DATABASE_TYPE=supabase # Options: supabase | postgresql | mysql
DATABASE_URL=postgresql://postgres:yourpassword@db.yourhost.supabase.co:5432/postgres

# Supabase Credentials (Required for Managed Supabase Storage & Realtime)
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
SUPABASE_SERVICE_ROLE_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...

# Payment Gateways (Optional for Online Merchant Invoicing)
PAYSTACK_SECRET_KEY=sk_live_...
NEXT_PUBLIC_PAYSTACK_PUBLIC_KEY=pk_live_...
STRIPE_SECRET_KEY=sk_live_...
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=pk_live_...

Multi-Database Engine Drivers

PFMS features an engine-agnostic database abstraction layer supporting 3 major relational database drivers:

Driver 1

Supabase PostgreSQL

Fully managed cloud PostgreSQL database with row-level security (RLS) and instant REST API generators.

Driver 2

Standard PostgreSQL

Self-hosted PostgreSQL 14/15/16 instances (AWS RDS, DigitalOcean, or local Docker containers).

Driver 3

MySQL / MariaDB

MySQL 8.0+ or MariaDB 10.6+ instances hosted on cPanel or Linux VPS servers.

Step-by-Step Setup Wizard Instructions

Step 1: Access `/setup`

Open your browser and navigate to `/setup`. The app automatically redirects uninitialized databases to the setup wizard.

Step 2: Choose Database Engine Driver

Click on your preferred database driver card. Input host, port, database name, username, and password.

Step 3: Automated Connection Guard Ping Test

The wizard executes an automated real-time ping test against the database server before allowing progression.

Step 4: Initialize Farm Profile & Superadmin User

Input main farm business name, create root Superadmin credentials (`owner@poultry.com`), and open the dashboard.
