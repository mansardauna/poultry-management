System Administration & Enterprise Management Guide

Comprehensive governance manual for super administrators and farm business owners. Explains role-based permissions (RBAC), multi-branch matrix transfers, white-label branding, CCTV WebRTC camera pairing, and SaaS subscription billing.

1. Role-Based Access Control (RBAC) Permissions Matrix

PFMS enforces strict multi-tenant role-based security permissions to protect sensitive financial records and system configuration:

Permission / Operational Scope SUPERADMIN ADMIN MANAGER STAFF
Super Admin CMS & SaaS Tenants Full Access Denied Denied Denied
Finance Ledgers & Payroll Processing Full Access Full Access View Only Denied
Multi-Branch Matrix & Stock Transfers Full Access Full Access Full Access Denied
CCTV WebRTC Live Camera Stream Full Access Full Access Denied Denied
Daily Egg Laying & Feed Consumption Logs Full Access Full Access Full Access Full Access

2. Enterprise Hub & White-Label Suite (`/dashboard/enterprise`)

Multi-Branch Matrix (`/branches`)

Aggregates real-time active flock count, daily egg crate output, and feed reserves across all regional farm branches. Allows seamless inter-branch stock transfers with automatic inventory adjustments.

White-Label Customization (`/whitelabel`)

Customize system identity for agricultural cooperatives and enterprise accounts. Upload custom farm logo, set custom subdomains, configure PDF report header watermarks, and select primary brand color themes.

REST API Keys & Webhooks (`/api`)

Generate bearer API tokens for external ERP integrations. Configure webhook listener URLs to receive real-time JSON event notifications for new sales, critical low-stock alerts, and batch mortality spikes.

3. CCTV WebRTC Camera Surveillance & QR Code Pairing (`/dashboard/cctv`)

Connect IP cameras or old smartphones as live streaming security cameras inside coop houses. Scan the WebRTC pairing QR code under `/dashboard/cctv` to establish a secure peer-to-peer WebRTC video stream for coop theft prevention and predator detection alerts.
