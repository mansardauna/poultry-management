Usage & Operational Guide

Step-by-Step Daily Workflows for Farm Attendants & Supervisors

1. Daily Egg Collection Logging (`/dashboard/eggs`)

  1. Navigate to `/dashboard/eggs` and click '+ Log Daily Lay'.
  2. Select collection date and choose layer flock batch ID (e.g. `B301`).
  3. Input total Good Eggs, Cracked Eggs, and Spoilt Eggs.
  4. System automatically calculates crate count using `Math.floor(Good Eggs / 30)` and logs remaining loose eggs.
  5. Log Cushion Audits to track nesting box cleanliness and reduce breakage rates.

2. Flock Mortality & Pen Transfers (`/dashboard/chickens`)

  • Register layer, broiler, or pullet batches with unique batch IDs.
  • Log daily mortality with cause (Heat Stress, Disease, Culling, Natural).
  • System automatically subtracts mortality from live active bird KPI cards.

3. Feed Inventory & Low Stock Alerts (`/dashboard/feed`)

Log daily Kg consumption per batch. Automatic red low-stock alert banners trigger on the main telemetry dashboard when feed reserves drop below safety thresholds.

4. Sales Invoices & WhatsApp Pay Links (`/dashboard/sales`)

  1. Click '+ Record New Sale' under `/dashboard/sales`. Select customer and product line.
  2. Click 'Generate Pay Link' to create hosted Paystack/Stripe checkout URL (`/pay-invoice/[id]`).
  3. Click 'Share to WhatsApp' to send invoice payment links directly to customer phones.
